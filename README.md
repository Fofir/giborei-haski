# Giborei Ha'Ski

A 16-bit ski platformer starring Dudu Pompi, built with [Excalibur.js](https://excaliburjs.com).
Based on the [Jelly Jumper sample](https://github.com/excaliburjs/sample-jelly-jumper) (BSD-2-Clause).

## Run

```sh
npm install
npm run dev
```

## Art

The player sprite sheet (`public/res/images/Player.png`) is generated from pixel maps in
`tools/make_dudu.py`. Edit the maps and run `python3 tools/make_dudu.py` to regenerate.
